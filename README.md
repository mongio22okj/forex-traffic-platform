# Forex Traffic Platform

Piattaforma web dedicata alla generazione e vendita di traffico qualificato per broker di trading Forex.

## Caratteristiche Principali

### Sezione Pubblica
- Landing page personalizzabili
- Video, immagini, recensioni
- Comparazioni tra piattaforme di trading
- Contenuti informativi per utenti interessati

### Dashboard Amministrativa
- Monitoraggio real-time delle performance
- Tracciamento impressions, clicks, registrazioni
- Analisi conversioni per campagna
- Statistiche per sorgente, paese, dispositivo, data
- Gestione multiple landing page
- Esportazione dati (Excel, CSV, PDF)
- Sistema di tracking broker/campagne
- Notifiche automatiche per variazioni significative

## Tecnologia Stack
- Backend: Node.js + Express.js
- Database: PostgreSQL
- Frontend: React.js
- Analytics: Custom tracking system

## Installazione

```bash
npm install
cp .env.example .env
npm run dev
```
